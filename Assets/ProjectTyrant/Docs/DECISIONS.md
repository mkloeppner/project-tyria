## M0 – Setup
- **Unity 6000.6.7f1 statt "6 LTS"** · Das vorhandene Projekt läuft auf 6.6; ein Versionswechsel ohne User wäre riskant. · Downgrade auf 6000.0 LTS.
- **Packages:** URP 17.6, Input System 1.20.1, Cinemachine 6.6.0 (API = Cinemachine 3.x, Namespace `Unity.Cinemachine`), ProBuilder 6.1.4, uGUI 2.6 (enthält TextMeshPro), Test Framework 1.8. · Alles, was die Leitplanken fordern.
- **Active Input Handling = "Both"** · New Input System ist Standard, Legacy bleibt als Fallback, weil die neue Backend-Einstellung erst nach Editor-Neustart greift und ein unbeaufsichtigter Neustart (EditorApplication.OpenProject) das MCP-Bridge-Setup gefährdet hätte. Der InputManager nutzt das neue System, sobald Geräte vorhanden sind, sonst Legacy-Input. · Nur "Input System Package (New)" + erzwungener Neustart.
- **TMP Essentials + URP-Auto-Assets nach `Assets/ProjectTyrant/` verschoben** (UI/TextMesh Pro, Data/Rendering) · Regel "nichts außerhalb anlegen"; GUIDs bleiben erhalten, TMP findet seine Settings über den Resources-Ordner. · Im Assets-Root lassen.
- **Tests unter `Scripts/Tests`, Render-Assets unter `Data/Rendering`, Editor-Builder unter `Scripts/Editor`** · Halten die vorgegebene Ordnerliste ein. · Eigene Top-Level-Ordner.
- **Zusätzliche Assembly `ProjectTyrant.Editor`** (Editor-only) für Szenen-/Daten-Builder · Builder brauchen UnityEditor-API, dürfen nicht in die Runtime. · Builder-Code in execute_code-Snippets (nicht versionierbar).
- **Kein Git-Commit** · Projektordner ist kein Git-Repository; ein neues Repo wurde bewusst nicht angelegt (nicht beauftragt). · `git init`.
